# Small scalar repairs of the S5 group construction

No improving matrix degeneration is constructed. This package explores
a relaxed construction target and proves a necessary condition for its
auxiliary corrections. The group-coordinate part retains integer vertex
weights; the auxiliary tensors may use arbitrary Laurent linear maps.

The source C[S5 x C2 squared] direct-sum D8 passes the exact degree-cost
comparison for M(18,18,20) at22499/10000. Its certified margin is
6805979977 at scale10^10. An actual correction witness is missing.
The [proof](proof.md) accounts for the auxiliary scalars, cyclic tensor
symmetrization, interpolation and the exact complex arithmetic model.

A finite C3-squared control has eight intended terms, two extra terms
with weights1 and-1, and a single scalar cancelling the negative term.
It verifies the actual Laurent correction, without an improving cost gate.

The new diagonal matrix argument bounds the rank of arbitrary auxiliary
corrections by the number of output coordinates occupied by nonpositive
extra terms. Nine exact Farkas circuits on disjoint output-coordinate
sets therefore exclude every rank-eight Laurent correction for the first
trade-free S5 pair model, for any integer vertex weights. The packet uses
417 monomials and239 third-leg coordinates. It also survives both earlier
commuting-trade and central four-matching tests. This is one fixed model,
not a sourcewide exclusion. Different vertex sets and mixed group maps
remain open. The proof is written and unreviewed.

The earlier weaker nine-circuit packet is retained separately: it proves
a lower bound only for individual monomial cancellations. The new output-
coordinate packet has the stronger arbitrary-rank correction scope.

Verification uses the maintained root dependencies. The reported root
intervals are checked by integer powers, not regenerated by numerical
optimization. Discovery uses optional NumPy/SciPy/python-sat. The weighted
commuting sampler now counts edge multiplicities, and checks every saved
incremental pair/owner histogram against full recomputation. This score
is only a discovery aid. No independent mathematical review, Lean
formalization or matrix exponent improvement is claimed.
