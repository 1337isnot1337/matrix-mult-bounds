# Registered question

Can the exact polynomial conic curve be modified to realize PR107's
prescribed full first jet, including its boundary velocity, rather than
only the same nonzero normal class?

The earlier degree-one/degree-three construction changes 32 boundary
entries on each first map. This investigation permits moving both
rank-one gauge roots and compensating both boundary cores, while
requiring a complete polynomial identity and exact first coefficients.

The delivered cubic/cubic curve answers this question for every complex
a,b,d, including d=0. Acceptance uses all complete source product
coefficients through degree six. It does not infer an all-order result
from a longer finite jet.

The next stronger question is whether PR107's specified second
coefficients also extend to an exact curve on d nonzero. This package
changes those coefficients and makes no such assertion.

preceding normal-class construction; PR107 is the fixed-jet source;
PR123 treats its separate d=0 fixed-two-jet fiber. PR133 and PR127 are
verification/audit continuations. No other mixed-chart prescribed-full-
