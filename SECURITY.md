# Security

This policy covers executable code, dependencies, and GitHub Actions workflows. Security fixes target `main`.

When private reporting is available, report vulnerabilities through **Security → Advisories → Report a vulnerability**.
If that option is unavailable, open an issue requesting a private reporting channel. Keep exploit details and credentials out of that issue.

In a private report, include the affected commit, reproduction steps, and the potential impact. Omit unrelated private data.

For a mathematical error or ordinary reproduction failure, open a [public issue](https://github.com/1337isnot1337/matrix-mult-bounds/issues/new/choose).
Those reports belong with the research evidence and claim history.
