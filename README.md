# Matrix multiplication bounds

A research workspace for the arithmetic exponent of matrix multiplication. The goal is a rigorously supported improvement below $\omega\le9/4$.

**This repository does not establish a smaller exponent.** Its initial contribution is an AI-derived analysis of a scalar relaxation, with exact finite experiments. The written proofs have no independent review or local Lean formalization.

## External baseline versus this project's work

OpenAI's October 2, 2026 paper proves the complex arithmetic bound $\omega\le9/4$. The [Big O Speedrun page](https://bigospeedrun.com/matrix-multiplication) lists that result as Lean Verified. This repository did not rebuild that Lean proof.

The bibliography separately attributes the classical tensor methods, later laser-method bounds, and the 2026 rectangular and field extensions. OpenAI's published proof is external work, not a result of this conversation.

The [initial research note](research/ai/2026-10-20/research_note.md) was generated by ChatGPT in a research session directed by the repository owner. It gives an explicit pointwise-minimal profile for the stated scalar assumptions:

$$
h_1=1,\qquad h_{a+1}=\left(1+\frac1{3a}\right)h_a,
\qquad P_*(a,b)=h_{\min(a,b)}\left(\max(a,b)+\frac{\min(a,b)-1}{2}\right).
$$

The recurrence already appears in OpenAI's proof. The local analysis supplies the matching two-variable profile and its pointwise optimality. It also gives a restricted packing obstruction, additional filtration inequalities, and a conditional improvement criterion. No claim of historical priority is made.

The profile satisfies the stated scalar constraints at $t=3/4$. This is a barrier for that relaxation, **not** a lower bound $\omega\ge9/4$ and not a construction of a tensor character.

## Reproduce the initial experiments

Use Python 3.10 or later. The recorded local run used Python 3.13.5 and SymPy 1.14.0.

```sh
python -m pip install -r research/ai/2026-10-20/requirements.txt
python -m unittest discover -s tests -v
python tools/replay.py
```

The replay uses temporary copies and leaves the archived files unchanged. It requires no network after dependency installation. Do not use Python's `-O` option: the archived verifier uses assertions.

| Completed scope | Count | Result |
| --- | ---: | --- |
| Scalar-profile grid assertions | 73,856 | Passed |
| Product-filtration inequalities | 353,664 | No violation of the matching profile |
| Binary weight candidates | 12,976 | No scored violation |
| Ternary weight candidates | 209,692 | No scored violation |
| Seeded random weight candidates | 20,000 | No scored violation |

The scalar program also verifies four symbolic identities. The filtration run covers 20,736 source quadruples. Candidate counts are not counts of distinct tensor isomorphism classes.

[Recorded replay results](results/bootstrap-2026-10-20/summary.json) and [verification limits](docs/verification.md) distinguish exact decisions from display-only floating-point values. Finite tests do not prove asymptotic claims.
